== Incident 12 postmortem: the october outage ==

Summary. On 14 October 2026 the home-lab cluster lost all ingress traffic for forty minutes. The proximate trigger was a certificate renewal that left the nginx ingress serving an expired chain.

== Timeline ==

At 21:03 the first alerts fired because external probes failed TLS handshakes. At 21:05 the on-call acknowledged and began triage. At 21:07 the nginx ingress logs showed x509 certificate expired errors on every virtual host. At 21:09 the team confirmed the renewal job had written the new certificate to the wrong secret name, so the ingress kept serving the old expired chain. At 21:12 the first remediation attempt copied the new certificate into the correct secret but the ingress pods did not reload because the reloader annotation was missing. At 21:15 the team restarted the ingress controller pods manually, which did not help because the secret reference in the ingress resource still pointed at the old name. At 21:18 a second attempt edited the ingress resource to reference the correct secret directly. At 21:21 the pods reloaded and served the new chain on the staging namespace ingress, confirming the fix pattern. At 21:24 the same edit was applied to the production ingress. At 21:26 external probes began passing again on most endpoints. At 21:29 the team noticed the media subdomain still failing because it uses a separate ingress object that had been forgotten in the first pass. At 21:32 the media ingress was patched as well. At 21:35 all probes were green. At 21:38 the incident was declared mitigated. At 21:41 the team wrote down the follow-up items. The follow-up items were: first, add the reloader annotation to every ingress-adjacent deployment so future certificate rotations reload automatically; second, consolidate the media subdomain ingress into the main ingress object so it cannot be forgotten again; third, extend the renewal job verification so it compares the served chain against the written secret and pages when they diverge for more than five minutes; fourth, schedule a game-day in November rehearsing exactly this failure mode. The verification requirement was explicit: the renewal job comparison check must run green in staging for seven consecutive days before it is enabled in production. At 21:48 the postmortem owner was assigned. At 21:52 the channel was quiet again. Total customer-visible impact was forty minutes of failed TLS handshakes on all public endpoints and an additional six minutes of degraded media streaming.

== Root cause ==

The root cause was a secret-name mismatch in the renewal job combined with a missing reloader annotation. The proposed-but-rejected fix of switching to cert-manager operator mode was rejected because the team prefers the static manifest workflow.
