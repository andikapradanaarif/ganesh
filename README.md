# Ganesh

A planned personal memory service for agents working across authorized projects.

The product must automatically preserve useful discoveries, help a fresh agent reuse them, and update or withdraw them when evidence changes, without routine owner summaries or semantic review.

Status: S0 local preparation and metadata-spool foundations are implemented and under test. No client hook has been installed, no real S0 experiment or release acceptance suite has run, and no memory service is deployed.
