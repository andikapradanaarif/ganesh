# Ganesh

A planned personal memory service for agents working across authorized projects.

The product must automatically preserve useful discoveries, help a fresh agent reuse them, and update or withdraw them when evidence changes, without routine owner summaries or semantic review.

Status: roadmap review and S0 preparation. No collector, experiment, memory service or acceptance suite has been run in this repository.

- [Roadmap and architecture review](docs/roadmap-architecture-review.md)
- [Contribution workflow](AGENTS.md)
- [Review issue #1](https://github.com/andikapradanaarif/ganesh/issues/1)

Go is the proposed initial language. The next implementation scope is the bounded S0 inventory and local metadata collector. Lite and the fuller gateway remain conditional on the supplied roadmap's decision gates.
